Q1 DCFL / Automata Which of the following languages is NOT a Deterministic Context-Free Language (DCFL)?
  • A {wwR : w ∈ {a, b}*} — reverse palindromes
  • B {bnabn : n ≥ 1}
  • C {bnan : n ≥ 1}
  • D {anban : n ≥ 1}
✔ Correct Answer
A — {wwR} is NOT a DCFL
Explanation

To recognise {wwR}, a machine must first push all characters of w onto a stack, then pop them while matching with wR. But the midpoint of the string is unknown — the machine cannot deterministically decide when w ends and wR begins. This inherent non-determinism means it can only be accepted by an NPDA, NOT a DPDA. Hence it is a CFL but NOT a DCFL.

Why Others Are DCFLs
  • B & D — {bnabn} and {anban}: The middle separator (a or b) is a unique sentinel. A DPDA pushes the first block, sees the separator, then pops while matching the second block — completely deterministic.
  • C — {bnan}: Classic DCFL. Push b's, then pop one per a. No ambiguity.
Extra for Exam

DCFL ⊂ CFL. Every DCFL is a CFL, but not every CFL is a DCFL. Key non-DCFLs to remember: {wwR}, {ww}, and languages that require "guessing" a midpoint. DCFLs are closed under complementation but NOT under union or intersection.

Q13 Regular Grammar Which defines a regular grammar for the language (ab)*a?
  • A G = ({S}, {a, b}, {S → abS | a}, S)
  • B G = ({S}, {a, b}, {S → aS | b}, S)
  • C G = ({S}, {a, b}, {S → abS | b}, S)
  • D G = ({S}, {a, b}, {S → bS | a}, S)
✔ Correct Answer
A — S → abS | a
Explanation

The language (ab)*a generates: a, aba, ababa, abababa, … Starting from S:

S → a (produces "a" directly ✓)
S → abS → aba (produces "aba" ✓)
S → abS → ababS → ababa ✓

This correctly matches (ab)*a. Option A is also a right-linear grammar (non-terminal always at right end), making it a valid regular grammar.

Why Others Are Wrong
  • B — S → aS | b: Generates strings of a's ending in b (e.g., aab). Completely wrong language.
  • C — S → abS | b: Terminal rule is b alone, so strings end in b. Not matching (ab)*a.
  • D — S → bS | a: Generates b*a — strings of b's followed by a. Wrong language.
Q14 Regular Expressions Which of the following is NOT a primitive regular expression?
  • A a
  • B λ (empty string)
  • C b
  • D (a + b)*
✔ Correct Answer
D — (a + b)* is NOT a primitive regular expression
Explanation

Primitive (atomic) regular expressions are defined as: ∅ (empty set), λ (empty string), and any single symbol from the alphabet (a, b, c, …). These are the base cases. (a + b)* is a compound expression built using union (+) and Kleene star (*) — it is NOT primitive.

Key Rule

Any regular expression that uses an operator (+ union, · concatenation, * Kleene star) is NOT primitive. It is a composed/derived expression.

Q15 CFL Properties Which statement is correct regarding Context-Free Languages (CFL)?
  • A Every CFL is regular.
  • B Every regular language is context-free.
  • C CFLs cannot be recognised by pushdown automata.
  • D CFLs are closed under intersection.
✔ Correct Answer
B — Every regular language is context-free
Explanation

The hierarchy: Regular ⊂ CFL ⊂ CSL ⊂ Recursively Enumerable. Since regular languages are a strict subset of CFLs, every regular language is also context-free.

Why Others Are Wrong
  • A: {anbn} is CFL but NOT regular (proved by Pumping Lemma). So not every CFL is regular.
  • C: Completely false — CFLs are EXACTLY the languages recognised by Pushdown Automata (PDA).
  • D: CFLs are NOT closed under intersection. Example: {anbncm} ∩ {ambncn} = {anbncn} which is NOT a CFL.
Closure Properties of CFL
  • Closed under: Union, Concatenation, Kleene star, Homomorphism
  • NOT closed under: Intersection, Complementation
Q17 Regular Grammar Identify the regular grammar from the options below.
  • A S → aS | A, A → bAc | bc
  • B S → aS | a, A → bA | b
  • C S → aS | A, A → abAc | bc
  • D S → aS | A, A → bAc | abc
✔ Correct Answer
B
Explanation

A regular grammar requires all productions to be either right-linear (A → aB or A → a) or left-linear (A → Ba or A → a). Option B satisfies this: S → aS (right-linear), S → a (terminal), A → bA (right-linear), A → b (terminal). All valid.

Why Others Are Wrong
  • A — A → bAc: Non-terminal A is in the MIDDLE, not at the right end. This makes it context-free, not regular.
  • C — A → abAc: Multiple terminals before and after the non-terminal — not regular.
  • D — A → bAc and A → abc: Same issue — non-terminal in the middle.
Q27 DFA Design DFA for L = {w : |w| mod 3 = 0}, Q = {1,2,3}, q₀ = 1, F = {1}. Which δ is correct?
  • A δ(1,a)=1, δ(1,b)=1, δ(2,a)=2, ... (self-loops)
  • B δ(1,a)=2, δ(1,b)=2, δ(2,a)=3, δ(2,b)=3, δ(3,a)=1, δ(3,b)=1
  • C δ(1,a)=2, δ(1,b)=1, δ(2,a)=3, ...
  • D δ(1,a)=3, δ(1,b)=3, ...
✔ Correct Answer
B
Explanation

The DFA tracks |w| mod 3. State 1 = 0 mod 3 (start & accept), State 2 = 1 mod 3, State 3 = 2 mod 3. On every character read, we move to the next state cyclically:

State 1 → (any symbol) → State 2
State 2 → (any symbol) → State 3
State 3 → (any symbol) → State 1 (accepted!)

Strings accepted: ε (length 0), aab (length 3), aaaaaa (length 6), etc.

Why Others Are Wrong
  • A: All states loop to themselves — every state accepts only if it's a final state. This DFA would accept ALL strings (or none), not just multiples of 3.
  • C: δ(1,b)=1 means 'b' doesn't advance the counter — string "b" would be accepted at length 1 incorrectly.
  • D: Jumps directly from state 1 to state 3 on first symbol — skips the "length 1" tracking entirely.
Q29 Regular Expressions Which RE represents L = {ε, c, ab, cc, cab, abc, abab, ccc, …}?
  • A c* · (a + b)
  • B (b + (a · c))*
  • C (c + (a · b))*
  • D (a + (b · c))*
✔ Correct Answer
C — (c + ab)*
Explanation

Pattern: the language consists of arbitrary arrangements of the "tokens" c and ab. So strings are built by choosing 'c' or 'ab' zero or more times:

ε = zero tokens ✓
c = one 'c' token ✓
ab = one 'ab' token ✓
cc = 'c' + 'c' ✓
cab = 'c' + 'ab' ✓
abc = 'ab' + 'c' ✓
abab = 'ab' + 'ab' ✓
Why Others Are Wrong
  • A — c*(a+b): Must end with a or b and cannot produce ε or cc.
  • B — (b + ac)*: Tokens are b and ac — produces strings like b, ac, bac, etc. Not matching.
  • D — (a + bc)*: Tokens are a and bc — produces a, bc, abc (=a+bc), etc. Generates "abc" differently and misses "ab".
Q41 Context-Free Grammar Which string is NOT generated by G = ({S,A,B}, {a,b}, {S→aaB, B→Aa, A→bBb|λ}, S)?
  • A aababa
  • B aabbabba
  • C aabbbabababa
  • D aabbababa
✔ Correct Answer
B — aabbabba (given in exam)
Verification of Valid Strings

All strings start with S → aaB. Then B → Aa → (bBb)a → … The grammar naturally generates strings of the form aa + (nested bBb expansions) + a chain. aabbabba cannot be derived because the structure of b-groups and a-sequences doesn't match the grammar's production pattern.

Exam Tip

For CFG derivation questions, always start from S and apply productions systematically. Track what each derivation step produces and verify character by character.

Q44 Pushdown Automata In NPDA, the transition function δ takes the current state, input symbol, and what else?
  • A Set of final states F
  • B Initial state q₀
  • C Current output symbol
  • D Current symbol on top of the stack
✔ Correct Answer
D — Top of Stack symbol
Explanation
NPDA δ: Q × (Σ ∪ {ε}) × Γ → 2^(Q × Γ*)

Inputs: (current state, input symbol, stack top symbol)
Output: set of (new state, stack string to push)

The stack top symbol is crucial — the PDA's behaviour depends on what's currently on top of the stack, enabling it to match nested structures like parentheses or {anbn}.

Q49 Regular Expressions Which language is represented by r = (bb)*(aa)*a?
  • A Odd b's followed by odd a's
  • B Even b's followed by odd a's
  • C Odd b's followed by even a's
  • D Even b's followed by even a's
✔ Correct Answer
B — Even number of b's followed by odd number of a's
Explanation
(bb)* → pairs of b's: ε, bb, bbbb, … → 0, 2, 4, … b's (EVEN)
(aa)*a → pairs of a's then one a: a, aaa, aaaaa, … → 1, 3, 5, … a's (ODD)

Examples: "a" (0 b's, 1 a), "bba" (2 b's, 1 a), "bbaaa" (2 b's, 3 a's) — all match.

Q56 Turing Machine For TM M = (Q, Σ, Γ, δ, q₀, b, F): (i) Γ is tape symbols. (ii) b ∈ Σ. Which is true?
  • A Only (ii)
  • B Neither
  • C Both
  • D Only (i)
✔ Correct Answer
D — Only (i) is true
Explanation

(i) TRUE: Γ is indeed the finite set of tape symbols, and Σ ⊆ Γ.

(ii) FALSE: The blank symbol b is in Γ (tape alphabet) but b ∉ Σ (input alphabet). This is a critical distinction — the blank b separates the input from unused tape cells, and it is never part of the input string itself.

Σ ⊂ Γ, and b ∈ Γ but b ∉ Σ
Q72 Regular Expressions For Σ = {a, b}, what language does the regex 'a + b' generate?
  • A {a, b}*
  • B {aa, ab, bb}
  • C {a, b}
  • D {λ, a, b}
✔ Correct Answer
C — {a, b}
Explanation

In regex notation, '+' (or '|') means union/OR. So 'a + b' means "either a or b" — exactly the set {a, b}. Do not confuse '+' in regex with arithmetic addition or Kleene plus.

Why Others Are Wrong
  • A — {a,b}*: This would be (a+b)* — all strings including ε.
  • D — {λ, a, b}: That would be (a+b+λ) or (a+b)? — includes empty string.
Q73 Regular Expressions Which of the following is NOT a valid regular expression over Σ = {a, b}?
  • A a
  • B b
  • C (a + b)* · (a + b)
  • D {a, b}
✔ Correct Answer
D — {a, b} is NOT a valid regular expression
Explanation

{a, b} is set notation, not regex notation. A regular expression uses symbols, operators (+, ·, *), and parentheses. Curly-brace set notation is from set theory / formal language description — it is not a valid regular expression syntax.

Q77 DFA Definition Which statement is INCORRECT about DFA M = (Q, Σ, δ, q₀, F)?
  • A The set of final states F may be empty.
  • B δ is defined for all states in Q and symbols in Σ.
  • C The initial state q₀ must be a member of Q.
  • D The set of states Q must be non-empty.
✔ Correct Answer (INCORRECT statement)
A — though debated (see explanation)
Explanation

Statements B, C, D are all definitionally true for any DFA. Statement A says "F may be empty" — formally, F ⊆ Q and F = ∅ is allowed (DFA accepts nothing). However, many textbooks and exam setters consider a DFA with empty F as degenerate/invalid, making A "incorrect" from that perspective. This is the intended answer in the exam.

Key DFA Facts
  • δ: Q × Σ → Q is a total function (defined for every state-symbol pair) — this distinguishes DFA from NFA.
  • Q must be non-empty (at least q₀ ∈ Q).
  • q₀ ∈ Q by definition.
Operating Systems
Q2 OS – Memory Where is the ready queue typically maintained in a modern OS?
  • A Secondary memory
  • B Tertiary memory
  • C Virtual memory
  • D Primary memory (RAM)
✔ Correct Answer
D — Primary Memory (RAM)
Explanation

The ready queue contains the Process Control Blocks (PCBs) of all processes that are loaded in memory and waiting for CPU time. It must be in RAM for the CPU scheduler to access it rapidly. Secondary memory is too slow; tertiary is even slower.

OS Queues Summary
  • Job queue: All processes in system (may be on disk)
  • Ready queue: In RAM — ready to execute
  • Device queues: In RAM — waiting for I/O
Q20 OS – System Calls Which provides OS services to user programs via an API?
  • A Demand paging
  • B Segmentation
  • C Virtual memory
  • D System call
✔ Correct Answer
D — System call
Explanation

A system call is the programmatic interface between a user-space application and OS kernel services. They are exposed as an API (e.g., POSIX in Unix). Examples: read(), write(), fork(), open(). When called, the CPU switches from user mode to kernel mode.

Why Others Are Wrong
  • Demand paging / Virtual memory / Segmentation are memory management techniques, not API mechanisms.
Q30 OS – Scheduling The 'job scheduler' in an OS is also known as the:
  • A Dispatcher
  • B Short-term scheduler
  • C Long-term scheduler
  • D Medium-term scheduler
✔ Correct Answer
C — Long-term scheduler
Explanation

The long-term (job) scheduler selects which jobs from the job pool (disk) to bring into the ready queue (RAM). It controls the degree of multiprogramming. It is invoked infrequently.

All 3 Schedulers
  • Long-term (Job) scheduler: Disk → Ready queue. Controls multiprogramming degree. Slow.
  • Short-term (CPU) scheduler: Ready queue → CPU. Very fast. Runs every few milliseconds.
  • Medium-term scheduler: Handles swapping — moves processes between RAM and disk to free memory.
  • Dispatcher: Performs the actual context switch — loads registers, switches to user mode.
Q33 OS – Threads (i) Multiple threads can exist in one process. (ii) A thread is a lightweight process. Which is true?
  • A Neither
  • B Only (i)
  • C Both (i) and (ii)
  • D Only (ii)
✔ Correct Answer
C — Both are true
Explanation

(i) TRUE: A process is a container for threads. A single process can have many threads (e.g., a browser has separate threads for UI, network, rendering).

(ii) TRUE: Threads are called "lightweight processes" because they share the parent process's memory space, code, and resources. Creating/switching threads is cheaper than full process creation.

Q34 OS – CPU Scheduling Calculate Avg TAT and Avg WT for P1(AT=0, BT=2), P2(AT=3, BT=1), P3(AT=5, BT=6) using FCFS.
  • A Avg TAT: 3, Avg WT: 3
  • B Avg TAT: 3, Avg WT: 0
✔ Correct Answer
B — Avg TAT: 3, Avg WT: 0
Calculation (FCFS)
P1: Arrives 0, BT=2. Start=0, End=2. TAT=2-0=2. WT=Start-AT=0-0=0
P2: Arrives 3, BT=1. CPU idle 2→3. Start=3, End=4. TAT=4-3=1. WT=3-3=0
P3: Arrives 5, BT=6. CPU idle 4→5. Start=5, End=11. TAT=11-5=6. WT=5-5=0

Avg TAT = (2+1+6)/3 = 9/3 = 3
Avg WT = (0+0+0)/3 = 0
Key Formulas
  • TAT = Completion Time − Arrival Time
  • WT = TAT − Burst Time
  • Response Time = Start Time − Arrival Time
Q46 OS – Memory Hierarchy Which statement about computer memory is INCORRECT?
  • A Main memory communicates with auxiliary memory through an I/O processor.
  • B Programs currently needed are transferred from main memory to auxiliary memory.
  • C Speed of main memory > auxiliary memory.
  • D Main memory communicates directly with CPU.
✔ Correct Answer (INCORRECT statement)
B — Direction is REVERSED
Explanation

The correct direction is: programs needed by the CPU are transferred FROM auxiliary memory (HDD/SSD) TO main memory (RAM), not the other way around. When a program is needed, the OS loads it into RAM for execution. Transferring to auxiliary memory is what happens during swapping (moving OUT of RAM).

Q50 OS – Kernel Access When software requires access to the OS kernel, it uses a:
  • A System call
  • B Virtual memory
  • C CUI
  • D GUI
✔ Correct Answer
A — System call
Explanation

A system call is the only safe, controlled mechanism for user-space programs to request kernel services. It triggers a CPU trap/interrupt to switch from user mode to kernel mode, execute the requested service, and return. CUI/GUI are user interfaces, not kernel access mechanisms.

Q58 OS – Memory Management Full form of TLB in OS memory management?
  • A Trivial Lookaside Buffer
  • B Translation Lookaside Buffer
  • C Trivial Lookaside Block
  • D Translation Lookaside Block
✔ Correct Answer
B — Translation Lookaside Buffer
Explanation

TLB is a hardware cache that stores recent page-number → frame-number mappings. Without TLB, every memory access requires TWO memory lookups: one for the page table + one for the actual data. With TLB, if the mapping is cached (TLB hit), only one lookup is needed. TLB hit ratio is typically 95–99%.

Effective Access Time = h × (TLB + Memory) + (1-h) × (TLB + 2×Memory)
where h = TLB hit ratio
Computer Networks
Q6 Networks – Topology Maximum links for a mesh topology with 10 nodes?
  • A 55
  • B 54
  • C 45
  • D 10
✔ Correct Answer
C — 45 links
Formula
Max links in full mesh = n(n-1)/2
= 10 × 9 / 2 = 90/2 = 45

This is also the number of edges in a complete graph K₁₀. Each of 10 nodes connects to 9 others, but each link is shared by 2 nodes.

Why A (55) Is Wrong

55 = 10×11/2 = C(11,2). That's the formula with n=11, not n=10. A common trap.

Q9 Networks – TCP/IP Which TCP/IP layer ensures packets arrive in sequence and error-free using ACKs?
  • A Transport layer
  • B Internet layer
  • C Physical layer
  • D Application layer
✔ Correct Answer
A — Transport Layer (TCP)
Explanation

TCP (Transmission Control Protocol) at the Transport layer provides: reliable delivery (ACKs + retransmissions), sequencing (sequence numbers), flow control (sliding window), and congestion control.

Why Others Are Wrong
  • Internet layer: IP is best-effort, connectionless — no guarantee of delivery or order.
  • Physical layer: Deals with bits on wire — no error correction at this level.
  • Application layer: Deals with application protocols (HTTP, SMTP) — not sequencing.
Q28 Networks – Protocols Which protocol allows two hosts to communicate character-by-character or line-by-line?
  • A TELNET
  • B FTP
  • C TFTP
  • D Anonymous FTP
✔ Correct Answer
A — TELNET
Explanation

TELNET (TELecommunication NETwork) provides a virtual terminal protocol — it allows a user to log into a remote host and interact character-by-character or line-by-line. It uses port 23. Note: TELNET transmits data in plaintext — SSH is its secure replacement.

Q31 Networks – Subnetting Subnet mask 255.255.240.0. Maximum hosts?
  • A 1024
  • B 2048
  • C 4094
  • D 4096
✔ Correct Answer
C — 4094
Calculation
255.255.240.0 = 11111111.11111111.11110000.00000000
Host bits = 4 (3rd octet) + 8 (4th octet) = 12 bits
Total addresses = 2¹² = 4096
Usable hosts = 4096 - 2 = 4094
(subtract network address and broadcast address)
Why D (4096) Is Wrong

4096 is the total number of addresses. But the network address (all host bits = 0) and broadcast address (all host bits = 1) cannot be assigned to hosts. So usable = 4096 − 2 = 4094.

Q54 Networks – ICMP ICMP detects and reports: (i) Dropped packets, (ii) Connectivity failure?

Q55 Networks – Routing Routing protocols for TCP/IP: (i) RIP, (ii) EGP?
  • A Both (i) and (ii)
  • B Only (ii)
  • C Only (i)
  • D Neither
✔ Correct Answer

EGP (Exterior Gateway Protocol): Used for inter-domain routing between autonomous systems. Largely replaced by BGP today, but is still a valid routing protocol.

Q67 Networks – Protocols RARP maps which address to which?
  • A Ethernet (48-bit) → IPv4 (32-bit)
  • B IPv4 (32-bit) → Ethernet (48-bit)
✔ Correct Answer
A — MAC → IP

Q7 DBMS – Constraints Which constraint specifies that a primary key cannot contain a NULL value?
  • A Foreign key constraint
  • B Domain constraint
  • C Key constraint
  • D Entity integrity constraint
✔ Correct Answer
D — Entity Integrity Constraint
Explanation

The Entity Integrity Constraint states: "No primary key attribute can be NULL." This ensures every entity (row) in a relation can be uniquely identified. A primary key with NULL would mean an entity that cannot be distinguished from others.

Why Others Are Wrong
  • Key constraint: States that primary key must be unique (no two rows same PK). Different from the NULL rule.
  • Domain constraint: Restricts values an attribute can take (e.g., age must be positive integer).
  • Foreign key constraint (Referential integrity): A foreign key value must match a PK in the referenced table or be NULL.

Q68 DBMS – Normalisation R1(A,B,C) — atomic attributes, A is the only candidate key. Which is NOT necessarily true?
  • A R1 may or may not be in BCNF.
  • B R1 is in 1NF.
  • C R1 is definitely in 3NF.
  • D R1 is in 2NF.
✔ Correct Answer (NOT necessarily true)
C — "Definitely in 3NF" is NOT guaranteed
Explanation

1NF ✓: Given — all attributes atomic and single-valued.

2NF ✓: Since A is a single-attribute key, there can be no partial dependency (partial dependency requires a composite key). So 2NF is always satisfied.

3NF — NOT guaranteed: If B → C exists and B is not a candidate key, there is a transitive dependency (A→B→C), violating 3NF. We don't know the FDs, so 3NF is not necessarily true.

BCNF — may or may not hold (same reasoning). This statement is trivially true as a "maybe" claim.

Normalisation Quick Reference
  • 1NF: Atomic values, no repeating groups
  • 2NF: 1NF + no partial dependencies on PK
  • 3NF: 2NF + no transitive dependencies
  • BCNF: Every determinant is a candidate key
Q70 DBMS – Relational Algebra Which relational algebra operator is NOT commutative?
  • A Union
  • B Intersection
  • C Division
  • D Natural Join
✔ Correct Answer
C — Division is NOT commutative
Explanation

Division R ÷ S ≠ S ÷ R in general — the schemas must be compatible in a specific direction. Union (A∪B=B∪A), Intersection (A∩B=B∩A), and Natural Join (R⋈S=S⋈R) are all commutative — order doesn't affect the result.

Q4 Algorithms – DP Which statement accurately describes Matrix Chain Multiplication?
  • A DP approach: Θ(n²)

Q16 Algorithms – Greedy Which problem CANNOT be solved optimally by a Greedy Algorithm?
  • A Dijkstra's (Single Source Shortest Path)
  • B Minimum Spanning Tree
  • C 0–1 Knapsack Problem
  • D Fractional Knapsack
✔ Correct Answer
C — 0–1 Knapsack
Explanation

In the 0-1 Knapsack, each item must be taken wholly or left entirely. A greedy choice (always pick highest value/weight ratio) may leave gaps that smaller items could fill more optimally. This requires Dynamic Programming for optimal solution.

Fractional Knapsack CAN be solved greedily — you can take fractions, so always picking highest ratio is always optimal.

Greedy vs DP Problems
  • Greedy works: Fractional Knapsack, MST (Prim/Kruskal), Dijkstra's, Huffman Coding, Activity Selection
  • DP needed: 0-1 Knapsack, Matrix Chain Multiplication, Longest Common Subsequence, Floyd-Warshall

Q32 Algorithms – Sorting Which statement is INCORRECT about Merge Sort?
  • A merge() time complexity is O(log n)
  • B It is stable.
  • C It uses divide and conquer.
  • D Worst case: O(n log n)
✔ Correct Answer (INCORRECT statement)
A — merge() is O(n), NOT O(log n)
Explanation

The merge() function merges two sorted subarrays of total size n by comparing elements one by one — it takes O(n) time. The O(log n) factor comes from the number of recursive levels (log n levels), and at each level, O(n) total work is done → overall O(n log n).

Total: O(n log n) = O(n) work per level × O(log n) levels
Merge Sort Key Facts
  • Stable? Yes — equal elements maintain relative order
  • In-place? No — needs O(n) extra space
  • Best/Avg/Worst: All O(n log n)
  • Best for linked lists (no extra space needed)
